# Memora: Plans

The roadmap is split by part of the project:

| Plan | Covers |
|---|---|
| [`memora-backend/plan.md`](memora-backend/plan.md) | Express + MongoDB API: security, bug fixes, code quality, performance, testing, deploy, and the latest route test results |
| [`memora-frontend/memora-fe/plan.md`](memora-frontend/memora-fe/plan.md) | React app: auth & session handling, config, following backend changes, performance, code quality, deploy |

When `AGENTS.md` mentions a numbered item like "`plan.md` 2.1", it means the **backend** plan. The numbers are unchanged.
